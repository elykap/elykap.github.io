# elykap.github.io — Kyle Poota

Personal software engineering portfolio. Static site (HTML, CSS, vanilla JS)
deployed via GitHub Pages at **kylepoota.com**.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

No build step or dependencies required. `index.html` lives at the repo root.
The resume is served from the latest GitHub Release (not committed to the repo).
